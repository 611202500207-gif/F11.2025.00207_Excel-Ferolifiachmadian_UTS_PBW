# KILISUCI SIGAP

Sistem Integrasi Gerak Cepat Aduan Pasien – aplikasi web statis untuk Tim Humas & Pengaduan Masyarakat RSUD Kilisuci Kota Kediri.

Dibuat dengan HTML5, CSS3, Bootstrap 5.3, dan JavaScript murni. Data disimpan di `localStorage` browser (tanpa server/database).

## Halaman

| File | Halaman |
|------|---------|
| `login.html` | Masuk dengan email yang sudah didaftarkan |
| `daftar.html` | Pendaftaran akun petugas |
| `index.html` | Home – dashboard monitoring real time |
| `aduan.html` | Buat Aduan – formulir pengaduan |
| `data.html` | Data & Tindak Lanjut – respon dan selesai |
| `profil.html` | Profil petugas + kelola role (Admin) |

## Menjalankan

Buka folder di VS Code, klik kanan `login.html` → **Open with Live Server**.

Ganti `assets/img/gedung-kilisuci.jpg` dengan foto gedung RSUD Kilisuci.
